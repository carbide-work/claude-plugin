# Carbide intake, public page, and communications

1. Read the relevant current settings before changing them: custom fields, lead sources, timeline options, outcome reasons, source definitions and values, referrers, request links, public page, project copy, reminders, and templates.
2. Preserve IDs referenced by existing requests or templates. Prefer archive/deactivate behavior exposed by the tool over inventing a deletion workflow.
3. Preview email or calendar content before updating it when a preview tool is available.
4. For sending domains and identities, report verification state precisely. Only request a verification check after the user says the required DNS record exists.
5. Sending referral email is an open-world, irreversible side effect. Confirm recipient and intent from the conversation immediately before calling it.

Most setup tools require `mcp.write` and an administrator role. Reads remain useful when the connection cannot configure.
